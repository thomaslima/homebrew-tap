# Thomaslima Tap

## How do I install these formulae?

`brew install thomaslima/tap/<formula>`

Or `brew tap thomaslima/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "thomaslima/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
